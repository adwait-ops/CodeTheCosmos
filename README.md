# CodeTheCosmos
This is a full stack project, where we have developed a website showing all the stages of evolution of stars, depending on their mass relative to the Sun. Since all stars have a different life cycle depending on their initial mass and temperature, we need to plot their life course using the HR diagram. 
##Tech Stack - 
###Front End - HTML, CSS, JavaScript library THREE.js
###Back End - Python
###Integration using APIs - Flask
